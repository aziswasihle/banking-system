# Banking System (C++)

A command line banking system written in C++.

## Features
- Login by name
- Check balance
- Withdraw
- Deposit
- Send cash to an 8-digit account number
- Menu that repeats until the user exits

## How to run
Open main.cpp in Code::Blocks, then build and run the program.
